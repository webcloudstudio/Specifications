# Ideas: Console

Backlog of potential future enhancements. Not committed to any build phase.

## Ideas

- **State reload on page load**: Pre-populate questionnaire form fields from saved SQLite state on document load.
- **Kanban drag-and-drop**: Allow moving cards between columns; persist column assignment to SQLite.
- **Live reload**: Watch `console.json` for changes and hot-reload without server restart.
- **Dark mode**: Toggle based on OS preference.
- **Review queue UI**: Dedicated REVIEW tab that surfaces items with `awaiting_review` state as actionable cards with approve/revise/reject buttons.
- **Report metadata**: Parse frontmatter from report Markdown files for display in the reports index.
- **Multi-project support**: Serve multiple `console.json` files from a single running instance.
