# Architecture: Console

| Field       | Value |
|-------------|-------|
| Version     | 20260531 V1 |
| Description | Modules, routes, and directory layout for the Console application. |

## Modules

| Module | Responsibility |
|--------|---------------|
| `Console/app.py` | FastAPI application: config loading, AGILE_PLAN.md state machine, route handlers, markdown rendering, questionnaire rendering, Kanban derivation, SQLite state |
| `Console/console.json` | Generated by `build_plan.sh --analysis` and deployed by `ProjectUpdate.sh`; configures tabs, documents, agile_plan paths |
| `Console/start.sh` | Start script — launches uvicorn from parent project directory as `Console.app:app` |

## Deployment

Console lives in `Prototyper/Console/` and is deployed to each promoted project:
- `ProjectInitialize.sh`: rsync `Prototyper/Console/` → `ProjectName/Console/`
- `ProjectUpdate.sh`: copy updates + deploy `Specifications/ProjectName/console.json`
- `build_plan.sh --analysis ProjectName`: writes `Specifications/ProjectName/console.json`

## Stack

Python / FastAPI / Uvicorn / SQLite / `markdown` library. No ORM. No external services.

## Routes

| Method | Path | Returns |
|--------|------|---------|
| GET | `/` | Console UI (HTMLResponse) |

| GET | `/api/document/{tab_id}/{doc_id}` | Rendered document HTML |

| GET | `/api/kanban` | Roadmap kanban (markdown heading-derived) |
| GET | `/api/state/{key}` | SQLite state record by key |

| GET | `/api/review` | Review actions and states from config |
| GET | `/api/questionnaires` | Questionnaire index with completion state |
| GET | `/api/reports` | Report index |
| GET | `/api/summary` | AGILE_PLAN summary: total, awaiting, approved |
| GET | `/api/objects` | All AGILE_PLAN objects with state and ACs |
| GET | `/api/board` | AGILE_PLAN objects grouped into Kanban columns |
| GET | `/api/objects/{oid}/evidence` | Rendered evidence HTML for one object |
| POST | `/api/objects/{oid}/decision` | Write approve/revise/reject to AGILE_PLAN.md |
| POST | `/api/objects/{oid}/defect` | Add PO acceptance criterion to AGILE_PLAN.md |

## Directory Layout

```
Console/
  app.py                         FastAPI application (generic — no project logic)
  console.json                   Project-specific configuration
  start.sh                       Service start script
  requirements.txt               Python dependencies
  README.md
  data/
    console_state.sqlite         SQLite state database (gitignored)
  evidence/
    README.md                    Evidence index
  questionnaires/
    README.md
    console_process.json         Default questionnaire template
  reports/
    README.md                    Report index
```

The `Console/` directory lives inside the project root. `start.sh` runs from the project root so Python can import `Console.app` as a module.

## Configuration Loading

`app.py` loads `Console/console.json` at module import time. `BASE_DIR` is the `Console/` directory. All relative paths in `console.json` are resolved relative to `BASE_DIR`.

## State Schema

```sql
create table if not exists document_state (
  key text primary key,
  document_id text not null,
  state text not null,
  payload_json text not null,
  updated_at text not null
);
```

State keys are namespaced: `questionnaire.{id}`, `review.{doc_id}.{item_id}`, `kanban.{phase_id}`.
