# Console

A reusable, config-driven local review surface generated by `oneshot2.sh` for any Prototyper project.

## Intent

The Console renders a project's documents, questionnaires, Kanban board, and review queues from a single `console.json` configuration file. All state (questionnaire answers, review decisions) is stored in local SQLite — source files are never modified.

The Console application contains no project-specific logic. Project bindings belong entirely in `console.json`.
