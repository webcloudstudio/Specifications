# Drydock

Integrate the Prototyper's Specification Driven Design with GitHub Spec Kit (informed by Tessl and Kiro), then publish the framework — using the Prototyper's own methodology to build the integration.

## Intent

Drydock is a specification project whose subject is the Prototyper itself. It starts from a single
`INTENT.md` seed and is driven through the standard pipeline — plan, console review, build,
refine — so that the act of integrating Spec Kit becomes a worked demonstration of the methodology.
See `INTENT.md` for the question, `IDEAS.md` for the published backlog.
