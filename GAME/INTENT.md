## Intent

Important: The INTENT file contains the highest level objectives of the project


**Purpose 1: Best of Breed Developer Framework for Agentic developers.**

GAME (working name) is a Python Framework to help Agentic Developers.  It solves MANY problems automatically for developers using a combination of injecting a section of text into every "conformed" projects AGENTS.md file, annotating certain files, and encapsulating your system capabilities.  

This is a best of breed developer experience for an individual developer 
    * Best Development Pracices (python focused for now)
    * Best Build Practices (Branding)
    * An Operations Dashboard
    * Capability Sharing with your circle of trust (capabilities, data, servers) as needed
    * A portal to manage projects with Simple Project Workflow
    * Consistent operations / Integrated Documentation / Other Enterprise Features

I envision that users will build projects or even vibe code them but those projects need to be shared securely.  
Projects built by users will include home automation, seamless communication, and sharing data like calendar and messaging -- information that is EXTREMELY sensitive.  These run within a home users firewall and their systems may be very vulnerable
from attacks that direction.  For design, I envision sharing stuff with your kids (simple/easy/clear). The real 
target audience is probably small teams of adults.

One core value is our exposing exposing users projects capabilities through the use of annotations.  This project 
has a service catalog of those capabilities and relies on them.  For example, application logging requires known log
locations.  Reporting on process run times and duration requires hooks within those processes (done by encapsulating service capabilities into bash scripts).  

We are using AI to keep a developers applications conformed so this tool can use them.  The Consistency is the big win.

Manage all your projects on a single Dashboard
    On a single set of dashboards where you have complete observability and control of your projects
    Provides a clear management framework for your projects
        Best for projects you want saved to git or which integrate with other projects
    You generate your application and then integrate with your environment
Projects can be anything you are working over time - and are archived when done.  
Unified view on your projects: status, health, operations, logs, documentation as appropriate.

system security is architected around rules.  If on the same hardware - no security. Shared resources must be explicity granted.   

**Purpose 2: Conform Existing and New Projects to Standards that Enable Purpose 1**

Seamlessly expose the needed services across all your projects and prototypes using minimally invasive approach

Specifically add bash scripts that encapsulate tool functionality in bin/ scritps and then enable a rest api that calls those scripts.  Other languages from Bash can be used if wanted.

Metadata on the project is provided within the project enabling it to expose its capabilities using best practices including 
functionality, logging, command and control, operations, and general/specific endpoints.  This metadata is aggregated in a 
service catalog that ensures unified operations and interoperability.  This platform ensures the UI capabilities.
